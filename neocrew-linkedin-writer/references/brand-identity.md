# NeoCrew Brand Identity Guide

## Who We Are
NeoCrew.ai is an autonomous software engineering platform that orchestrates 51 specialized AI agents to build enterprise-scale applications. The platform operates across 4 pillars - Discover, Design, Blueprint, and Build - taking any idea from raw concept to a fully tested, deployment-ready GitHub repository.

This isn't a chatbot that writes code. It's a deterministic engineering pipeline with parallel execution, self-healing quality gates, and human-in-the-loop approval at every stage boundary.

## How It Actually Works

### Discover (Idea → PRD)
A Planner agent breaks the idea into PRD modules. Multiple agents draft sections in parallel. A Validator cross-checks for consistency. A Patcher resolves gaps. An Assembler stitches the final PRD - generating zero new text, purely deterministic.

### Design (PRD → UI)
A Screen Inventory agent mathematically maps every screen needed. Design agents generate all UI screens in parallel. An Iteration agent processes feedback. A Validator ensures nothing was dropped.

### Blueprint (UI → Technical Spec)
14 agent types across 5 layers of parallel execution. Entity discovery, schema generation, API design, platform architecture, domain repositories. Integration architects map every UI screen to API endpoints. A Coverage Checker exposes reasoning for human verification.

### Build (Spec → Deployed Code)
23 agents execute code in an isolated E2B sandbox. Backend and frontend dev agents write logic with continuous validation (Flake8, MyPy, PyTest). 6 parallel review layers check architecture, standards, test depth, and design fidelity. Failed code triggers self-healing correction loops before merge.

## MANDATORY Formatting Rule
NEVER use emdashes (the long dash character). Use hyphens (-) or rewrite the sentence instead. This applies to all content across all channels. No exceptions.

## Phrases to Avoid
- "Revolutionary" / "Game-changing" / "Disruptive"
- "AI-powered" as a standalone value prop
- Naming specific competitor tools (don't call out Lovable, Replit, Cursor, etc. by name)
- Startup pitch deck buzzwords
- Overselling or making promises beyond what the pipeline delivers
- "Co-founder" for anyone at Headstart (Amit is Director)
